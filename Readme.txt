Procedimiento de ejecución:
---------------------------

1. Ejecutar el archivo .exe (la primera vez puede demorar en abrirse).
2. Colocar la ventana de tiempo de búsqueda.
3. Abrir el archivo Excel que se encuentra dentro de la misma carpeta.
4. Click en "Buscar". Luego de unos segundos, generará la carpeta "reports" con el archivo resultante dentro de la misma
